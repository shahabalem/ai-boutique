\strategyPart{12 \textbar\ Work Transformation}{Work and Process Transformation}

The unit of AI value is the redesigned task, not the model. This part
classifies work, sequences process redesign, and defines human-in-the-loop
design.

\section{Task-level classification}

\begin{itemize}
  \item Tasks that can be \textbf{fully automated} — deterministic, rule-based, high-volume.
  \item Tasks that can be \textbf{AI-assisted} — drafting, search, analysis, recommendation.
  \item Tasks that require \textbf{human judgment} — ambiguous, high-stakes, ethical.
  \item Tasks that should \textbf{remain human-controlled} — regulatory, reputational, empathic.
  \item \textbf{New tasks created by AI} — prompt design, output verification, agent supervision.
\end{itemize}

\section{Process redesign sequence}

\begin{enumerate}
  \item \textbf{Remove} unnecessary steps before automating anything.
  \item \textbf{Simplify} approval chains.
  \item \textbf{Standardize} data and definitions.
  \item \textbf{Identify} tasks suitable for AI.
  \item \textbf{Define} human checkpoints and decision rights.
  \item \textbf{Automate} execution where risk allows.
  \item \textbf{Measure} outcomes continuously.
\end{enumerate}

\section{Assistance versus task replacement}

Organizations should not replace people based only on technical capability;
they should redesign work by separating tasks into activities AI can
automate, activities AI can assist with, and responsibilities that must
remain human-led [Anthropic; Microsoft agent framework].

\begin{itemize}
  \item \textbf{Assistance model} — AI helps when judgment, context or
        accountability matters (strategy, hiring, legal, medical, executive
        and negotiation decisions).
  \item \textbf{Partial replacement} — AI replaces parts of a job that are
        repetitive, rule-based, verifiable and low-risk (data entry,
        classification, transcription, standard reports).
  \item \textbf{Full task automation} — AI performs an entire task when it is
        narrowly defined, permissions are limited, results are validated and
        consequences of failure are bounded.
  \item \textbf{Human-only responsibility} — fundamental rights, employment
        decisions, legal accountability, safety-critical outcomes and
        high-value transactions remain human-led.
\end{itemize}

\section{The eight autonomy factors}

Before granting autonomy, assess: \textbf{task repetition}, \textbf{task
complexity}, \textbf{data structure and reliability}, \textbf{error cost and
reversibility}, \textbf{required human judgment} (empathy, ethics,
negotiation, accountability), \textbf{explainability and auditability},
\textbf{reversibility and rollback}, and \textbf{permission scope} (systems,
data, actions, external communication, spend) [NIST AI RMF; OWASP].
